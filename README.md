# 📝 To-Do List App (Python)

A simple command-line To-Do List application built with Python. This project lets users add, view, complete, and delete tasks. All tasks are saved in a local JSON file so your data stays even after closing the program.

## Features

- ➕ Add new tasks
- 📋 View all tasks with their status
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Tasks saved automatically in `tasks.json`
